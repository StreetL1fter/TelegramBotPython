# 🤖 Smart Fitness Coach Bot

Telegram-бот для систематических тренировок с персонализацией под уровень подготовки.  
Создан для тех, кто хочет **расти в силе осознанно** — от новичка до продвинутого.

---

## 🌟 Возможности

### 🔐 Безопасность и управление
- **Разделение ролей**: администратор vs гость
- Только администраторы способны просматрировать количество людей которые приобрели персональное введение.

### 🏋️‍♂️ Программы тренировок
- Подбор циклов **по стажу и опыту**:
  - Начинающий (меньше 3-х лет)
  - Продвинутый (больше 3-х лет)
  - Специализированные (жимовые программы)

### 📚 Образовательный контент
- Гайды по технике
- Жимовые раскладки (bench press schemes)
- PDF/DOCX/XLSX-файлы с подробными инструкциями

### 💬 Обратная связь
- Пользователи могут отправлять **feedback** администратору
- Улучшение контента на основе реальных запросов

### 🚧 В разработке
- 💳 **Платёжная система** (YooKassa) — покупка персонального введения
- 🤖 **ИИ-ассистент** — анализ целей, рекомендации, адаптация программ
- 📊 Трекинг прогресса (вес, повторения, недели)

---

## 🛠 Технологии

- **Python 3.10+**
- **aiogram 3.x** — асинхронный Telegram-фреймворк
- **SQLite** — локальное хранение данных пользователей
- **YooKassa** — приём платежей (внедряется)
- **Role-Based Access Control (RBAC)** — безопасность по ролям
